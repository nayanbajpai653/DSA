1. Hashing Kya Hai?

Hash function, bucket, aur O(1) ka raaz
▼
Hashing ek technique hai jisme ek Hash Function key ko ek index (bucket) mein convert karta hai. Phir value us index pe store hoti hai. Isliye koi bhi value O(1) mein milti hai – bina saari values scan kiye!

📚 Sochlo dictionary – "apple" word directly 'A' section mein jaata hai, poora dictionary scan nahi karte!

Hash Function Kaise Kaam Karta Hai?

index = hashFunction(key) % tableSize

Example: keys = {10, 22, 37}, tableSize = 7
• 10 % 7 = 3 → bucket 3
• 22 % 7 = 1 → bucket 1
• 37 % 7 = 2 → bucket 2

Collision Kya Hoti Hai?

Jab do alag keys ka hash same bucket pe aaye – yeh collision hai!
Example: 10 % 7 = 3, aur 17 % 7 = 3 → dono ek hi bucket mein!

Solutions:
1. Chaining – bucket mein linked list rakho (Java HashMap yahi karta hai)
2. Open Addressing – agle khaali bucket mein rakho
Bohot zyada collisions ho toh performance O(1) se O(n) ho jaati hai – worst case mein!

HashMap – Full Usage

Python
  map = {}
  # Insert / Update
  map["apple"] = 3
  map["banana"] = 5
  # Get
  map.get("apple")                # 3
  map.get("mango", 0)             # 0 (default if not found)
  # Check existence
  "apple" in map                  # True
  5 in map.values()                # True (checks values)
  # Delete
  map.pop("banana", None)
  # Iterate
  for k, v in map.items():
    print(f"{k} → {v}")
  # Size / isEmpty
  len(map); not bool(map)

HashSet – Full Usage

Python
  s = set()
  s.add(10); s.add(20); s.add(10)   # duplicate ignored
  10 in s                           # True
  s.remove(20)
  print(s)                           # {10}
Jab sirf "kya yeh element exist karta hai?" check karna ho – HashSet best hai. Key-Value chahiye toh HashMap.

4. Important Hashing Patterns

Frequency count, Two Sum, Anagram – sab patterns
▼

🔹 Pattern 1: Frequency Counting

Array mein har element kitni baar aaya – HashMap se O(n) mein!
Python
  # Frequency count – most common pattern
  from collections import Counter
  freq = Counter(arr)
  # or manual:
  freq = {}
  for x in arr:
    freq[x] = freq.get(x, 0) + 1
  # Now frequency of each element is O(1) lookup

🔹 Pattern 2: Two Sum – Classic!

Python
  def twoSum(nums, target):
    mp = {}
    for i, num in enumerate(nums):
      complement = target - num
      if complement in mp:
        return [mp[complement], i]
      mp[num] = i
    return []
  # O(n) time, O(n) space

🔹 Pattern 3: Anagram Check

Python
  def isAnagram(s, t):
    if len(s) != len(t): return False
    from collections import Counter
    return Counter(s) == Counter(t)
  # Or manual counting with dicts for O(n) time

🔹 Pattern 4: Subarray Sum = K

Python
  def subarraySum(nums, k):
    mp = {0: 1}
    count = 0
    prefix = 0
    for x in nums:
      prefix += x
      count += mp.get(prefix - k, 0)
      mp[prefix] = mp.get(prefix, 0) + 1
    return count
  # O(n) time

🔹 Pattern 5: Longest Consecutive Sequence

Python
  def longestConsecutive(nums):
    s = set(nums)
    maxLen = 0
    for x in s:
      if x - 1 not in s:  # sequence start
        length = 1
        while x + length in s:
          length += 1
        maxLen = max(maxLen, length)
    return maxLen
  # O(n) expected
Subarray sum = k type problems mein Prefix Sum + HashMap combo bohot powerful hai – O(n) mein solve ho jaata hai!
