1. Stack – LIFO (Last In, First Out)

Jo last mein aaya, woh pehle jaayega
▼
Stack ek data structure hai jisme sirf ek end (top) se insert aur remove hota hai. Jo element sabse baad aaya, woh sabse pehle niklega – LIFO!

🥞 Real life: Plate ki stack – upar se daalo, upar se nikalo!

Stack Operations

OperationDescriptionTime
push(x)Top pe element daaloO(1)
pop()Top se element nikaloO(1)
peek()/top()Top element dekho, remove mat karoO(1)
isEmpty()Stack khaali hai?O(1)
size()Kitne elements hainO(1)*
size() complexity depends on implementation: If you maintain a counter variable (increment on push, decrement on pop), it's O(1). If you count elements every time, it's O(n) – for n = 450, you'd traverse all 450 elements!

Stack Implementation

Python
  # Built-in list as stack
  st = []
  st.append(10)          # [10]
  st.append(20)          # [10, 20]
  st.append(30)          # [10, 20, 30]
  st.pop()               # 30 nikla -> [10, 20]
  st[-1]                 # 20 (peek)
  len(st) == 0           # isEmpty check

  # Using collections.deque if needed

  stack = deque()

  stack.pop()

2. Queue – FIFO (First In, First Out)

Jo pehle aaya, woh pehle jaayega
▼
Queue ek data structure hai jisme rear (back) se insert aur front se remove hota hai. Jo element pehle aaya, woh pehle niklega – FIFO!

🚌 Real life: Bus ki line – jo pehle queue mein aaya, woh pehle bus mein chadhega!

Visual – Queue

10 (Front)

Queue Operations

OperationDescriptionTime
enqueue/offer(x)Rear se add karoO(1)
dequeue/poll()Front se remove karoO(1)
peek()/front()Front element dekhoO(1)
isEmpty()Queue khaali hai?O(1)
Python
  from collections import deque
  q = deque()
  q.append(10)    # enqueue -> [10]
  q.append(20)    # enqueue -> [10, 20]
  q.append(30)    # enqueue -> [10, 20, 30]
  q.popleft()     # dequeue -> 10 removed, [20, 30]
  q[0]            # peek -> 20 (no remove)

Queue ke Uses

🔸BFS (Graph/Tree Traversal) – level by level traverse karna

🔸Printer Queue – print jobs ka order

3. Deque (Double-Ended Queue)

Dono ends se add/remove – versatile structure
▼
Deque (Double Ended Queue) mein dono ends se insert aur delete kar sakte ho. Stack aur Queue dono ki properties ek saath! 
Python
  from collections import deque
  dq = deque()
  dq.appendleft(10)   # front pe add
  dq.append(20)       # back pe add
  dq[0]               # peekFirst (front)
  dq[-1]              # peekLast (back)
  dq.popleft()        # pollFirst (remove front)
  dq.pop()            # pollLast (remove back)

Deque as Stack

Python
  # Use deque as stack (push/pop from left)
  dq.appendleft(10)   # push
  dq.popleft()        # pop

Classic Problem: Sliding Window Maximum

Python
  from collections import deque
  def maxSlidingWindow(nums, k):
    dq = deque()
    res = []
    for i, val in enumerate(nums):
      if dq and dq[0] < i - k + 1:
        dq.popleft()
      while dq and nums[dq[-1]] < val:
        dq.pop()
      dq.append(i)
      if i >= k - 1:
        res.append(nums[dq[0]])
    return res
Deque, Stack aur Queue dono replace kar sakta hai – interview mein monotonic deque bahut kaam aata hai!

4. Stack ke Important Problems

Classic problems jo har interview mein aate hain

✅ 1. Valid Parentheses – O(n)

Opening bracket aaya? Push karo. Closing aaya? Top se match karo. Agar match nahi toh invalid!
Python
  def isValid(s):
    st = []
    for c in s:
      if c in '({[':
        st.append(c)
      else:
        if not st:
          return False
        top = st.pop()
        if c == ')' and top != '(': return False
        if c == '}' and top != '{': return False
        if c == ']' and top != '[': return False
    return len(st) == 0

✅ 2. Next Greater Element – O(n)

Monotonic Stack use karo. Har element ke liye, stack mein chhote elements pop karte jao – current element unka NGE hai!
Python
  def nextGreater(arr):
    n = len(arr)
    res = [-1] * n
    st = []  # store indices
    for i, val in enumerate(arr):
      while st and arr[st[-1]] < val:
        res[st.pop()] = val
      st.append(i)
    return res

✅ 3. Min Stack – O(1) min access

Python
  class MinStack:
    def __init__(self):
      self.st = []
      self.minSt = []
    def push(self, val):
      self.st.append(val)
      m = val if not self.minSt else min(val, self.minSt[-1])
      self.minSt.append(m)
    def pop(self):
      self.st.pop(); self.minSt.pop()
    def getMin(self):
      return self.minSt[-1]

✅ 5. Queue using 2 Stacks

Python
  class QueueUsing2Stacks:
    def __init__(self):
      self.s1 = []
      self.s2 = []
    def enqueue(self, x):
      self.s1.append(x)
    def dequeue(self):
      if not self.s2:
        while self.s1:
          self.s2.append(self.s1.pop())
      return self.s2.pop()
Monotonic Stack (Decreasing/Increasing) – jab "next greater/smaller" type problems dikhein, yahi use karo!

5. Priority Queue (Heap)

Queue mein priority ke hisaab se order – Min/Max Heap
▼
Normal Queue mein pehle aaya pehle gaya. Priority Queue mein priority ke hisaab se nikalta hai. Andar Min-Heap ya Max-Heap hota hai.

🏥 Real life: Hospital emergency – serious patient pehle jaayega chahe baad mein aaya ho! 
Python
  import heapq
  # Min-heap (default)
  minPQ = []
  heapq.heappush(minPQ, 30)
  heapq.heappush(minPQ, 10)
  heapq.heappush(minPQ, 20)
  heapq.heappop(minPQ)   # 10 niklega (minimum)

  # Max-heap using negatives
  maxPQ = []
  heapq.heappush(maxPQ, -30)
  heapq.heappush(maxPQ, -10)
  heapq.heappush(maxPQ, -20)
  -heapq.heappop(maxPQ)  # 30 niklega (maximum)

Priority Queue ke Uses

🔸Dijkstra's Algorithm – shortest path
🔸Top K elements – array mein K largest/smallest
🔸Merge K Sorted Lists
🔸Median of Stream – do heaps se
PQ ka insert aur delete O(log n) hai – array ke O(1) se slow, lekin O(n) sorted array se fast!
