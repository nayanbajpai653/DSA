1. Linked List Kya Hai?

Definition, structure, array se comparison
▼
Linked List ek linear data structure hai jisme data Nodes mein store hota hai. Har node mein 2 cheezein hoti hain:
1. Data – actual value
2. Next Pointer – agli node ka address

Array ke unlike, memory contiguous nahi hoti – nodes memory mein kahin bhi ho sakte hain!

2. Types of Linked Lists

Singly, Doubly, Circular – teeno detail mein
▼

1️⃣ Singly Linked List

Har node ka sirf next pointer hota hai. Ek hi direction mein travel kar sakte ho – forward.
⌛Time: Search/Access O(n), insert at head O(1), insert at tail O(n) without tail pointer.

2️⃣ Doubly Linked List

Har node mein prev aur next dono pointers hote hain. Dono directions mein travel karo!
Python
  class DNode:
    def __init__(self, val):
    self.data = val
    self.prev = None
    self.next = None
✅Dono taraf traverse ho sakta hai
✅Delete operation easier hai (prev pointer available hai)
❌Extra memory (extra pointer ki wajah se)
⌛Time: Search O(n), insert/delete at known position O(1), head/tail operations O(1).

3️⃣ Circular Linked List

Last node ka next NULL ki jagah pehle node ko point karta hai. Ek loop ban jaata hai!
✅Use: Round-robin scheduling, Music playlist loop, Circular buffer
⌛Time: Search O(n), insert/delete head or tail O(1) if tail pointer maintained.
Circular LL mein traverse karte waqt NULL check nahi chalega – starting node check karna padega warna infinite loop!
⚙️

3. Operations with Code

Insert, Delete, Search – poori detail mein
▼

📌 Insert at Head – O(1)

Python
  def insertAtHead(head, val):
    newNode = Node(val)
    newNode.next = head
    return newNode  # new head

📌 Insert at Tail – O(n)

Python
def insertAtTail(head, val):
  newNode = Node(val)
  if not head:
    return newNode
  curr = head
  while curr.next:
    curr = curr.next
  curr.next = newNode
  return head

📌 Delete a Node – O(n)

Python
def deleteNode(head, val):
  if not head:
    return None
  if head.data == val:
    return head.next
  curr = head
  while curr.next and curr.next.data != val:
    curr = curr.next
  if curr.next:
    curr.next = curr.next.next
  return head

📌 Traverse / Print – O(n)

Python
def printList(head):
  curr = head
  while curr:
    print(f"{curr.data} → ", end='')
    curr = curr.next
  print('NULL')

4. Important Problems (Must Know!)

Reverse, Cycle detect, Middle, Merge – sab code ke saath
▼

🔄 1. Reverse a Linked List – O(n)

3 pointers use karo: prev, curr, next. Har step mein curr ka next, prev ko point karo.
Python
def reverse(head):
  prev, curr = None, head
  while curr:
    nxt = curr.next
    curr.next = prev
    prev = curr
    curr = nxt
  return prev  # new head

🔁 2. Detect Cycle – Floyd's Algorithm

Slow pointer 1 step aage jaata hai, Fast pointer 2 steps. Agar cycle hai toh woh zaroor milenge!
Python
def hasCycle(head):
  slow = fast = head
  while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:
      return True
  return False

🎯 3. Middle of Linked List

Slow 1 step, Fast 2 steps. Jab fast end pe pahunche, slow middle pe hoga!
Python
def findMiddle(head):
  slow = fast = head
  while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
  return slow  # middle node

🔀 4. Merge Two Sorted Lists

Python
  def mergeSorted(l1, l2):
    if not l1: return l2
    if not l2: return l1
    if l1.data <= l2.data:
      l1.next = mergeSorted(l1.next, l2)
      return l1
    else:
      l2.next = mergeSorted(l1, l2.next)
      return l2

🔢 5. Kth Node from End – O(n)

Python
  # Two pointer trick – advance fast by k steps
  def kthFromEnd(head, k):
    fast = slow = head
    for _ in range(k):
      fast = fast.next
    while fast:
      slow = slow.next
      fast = fast.next
    return slow  # slow now at kth-from-end
