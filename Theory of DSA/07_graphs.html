1. Graph Kya Hai? Basic Terms

Vertices, Edges, Types – sab kuch
▼
Graph ek data structure hai jisme Vertices (Nodes) aur Edges (Connections) hote hain. Tree bhi ek special graph hai (connected + acyclic)!

🌍 Real life: Google Maps (cities = nodes, roads = edges), Facebook (users = nodes, friendship = edges), Internet (servers = nodes, links = edges)

2. Graph Representation

Adjacency Matrix vs Adjacency List – kab kaunsa?
▼

1️⃣ Adjacency Matrix

V×V ka 2D array. matrix[i][j] = 1 agar i aur j ke beech edge hai.
Space: O(V²) | Dense graphs ke liye theek hai. 
Python
  matrix = [[0] * V for _ in range(V)]
  # Edge A-B add karo (undirected)
  matrix[A][B] = 1
  matrix[B][A] = 1
  # Weighted edge
  matrix[A][B] = weight
  # Edge hai ya nahi: O(1) check
  if matrix[u][v] != 0:
    ...
✅Edge existence O(1) mein check karo
❌O(V²) space – sparse graphs mein waste hai
❌Neighbors nikalne mein O(V) lagta hai

2️⃣ Adjacency List ⭐ (Most Used)

Har vertex ki ek list hoti hai jisme uske neighbors hote hain.
Space: O(V + E) | Sparse graphs ke liye best! 
Python
  # Adjacency List banao
  adj = [[] for _ in range(V)]

  # Edge add karo (undirected)
  adj[u].append(v)
  adj[v].append(u)

  # Weighted edge (pair store karo)
  adj = [[] for _ in range(V)]
  adj[u].append((v, weight))

  # Neighbors traverse karo
  for neighbor in adj[node]:
    ...  # O(degree)
✅Space efficient – O(V+E)
✅Neighbors quickly milte hain
❌Edge existence O(degree) mein – O(1) nahi
Interview mein hamesha Adjacency List se shuru karo – yeh real-world mein zyada useful hai!

3. BFS – Breadth First Search

Level by level traverse – Queue use karta hai
▼
BFS pehle starting node ke saare neighbors visit karta hai, phir unke neighbors, phir unke... Level by level! Queue use hoti hai.

🏘️ Sochlo ghar se shuru karo – pehle padosi ghar, phir unke padosi, phir unke...

BFS Steps

1️⃣Start node ko queue mein daalo, visited mark karo
2️⃣Queue se node nikalo, uske saare unvisited neighbors queue mein daalo
3️⃣Queue khaali hone tak repeat karo
Python
  from collections import deque

  def bfs(adj, start, V):
    visited = [False] * V
    q = deque()
    visited[start] = True
    q.append(start)
    while q:
      node = q.popleft()
      print(node, end=' ')
      for neighbor in adj[node]:
        if not visited[neighbor]:
          visited[neighbor] = True
          q.append(neighbor)
  # Time: O(V+E) | Space: O(V)

BFS ke Uses

🔸Shortest Path – unweighted graph mein BFS shortest path guarantee karta hai
🔸Level Order Traversal – Tree mein
🔸Connected Components – kaun-kaun se nodes connected hain
🔸Bipartite Check
🔸Multi-source BFS – multiple starting points (e.g., Rotten Oranges problem)
BFS = Shortest Path (unweighted). Weighted graph mein Dijkstra use karo!
🌀

4. DFS – Depth First Search

Deep jao phir backtrack – Stack/Recursion use karta hai
▼
DFS ek path pe jitna deep ja sake jaata hai, phir backtrack karta hai aur doosra path try karta hai. Stack ya Recursion use hoti hai.

🌳 Sochlo maze mein ek direction mein jaate raho jab tak dead-end na mile, phir wapas aao! 
Python – Recursive DFS
  def dfs(adj, visited, node):
    visited[node] = True
    print(node, end=' ')
    for neighbor in adj[node]:
      if not visited[neighbor]:
        dfs(adj, visited, neighbor)
  # Time: O(V+E) | Space: O(V) recursion stack
Python – Iterative DFS (Stack)
  def dfsIterative(adj, start, V):
    visited = [False] * V
    st = [start]
    while st:
      node = st.pop()
      if not visited[node]:
        visited[node] = True
        print(node, end=' ')
        for n in adj[node]:
          st.append(n)

DFS ke Uses

🔸Cycle Detection – directed aur undirected dono mein
🔸Topological Sort – dependencies ka order
🔸Connected Components / Islands
🔸Path finding – koi bhi path dhundna
🔸Strongly Connected Components (Kosaraju's)

BFS vs DFS – Kab Kaunsa?

5. Important Graph Algorithms

Dijkstra, Topo Sort, Union-Find, Cycle Detection
▼

🔹 Dijkstra's Algorithm – Shortest Path (Weighted)

Weighted graph mein ek source se sab nodes ka shortest path nikalta hai. Priority Queue (Min-Heap) use karta hai. 
Python
  import heapq

  def dijkstra(adj, src, V):
    dist = [float('inf')] * V
    dist[src] = 0
    pq = [(0, src)]  # (distance, node)
    while pq:
      d, u = heapq.heappop(pq)
      if d > dist[u]:
        continue  # stale entry
      for v, w in adj[u]:
        if dist[u] + w < dist[v]:
          dist[v] = dist[u] + w
          heapq.heappush(pq, (dist[v], v))
    return dist  # O((V+E) log V)
Dijkstra negative weights ke saath kaam nahi karta! Negative edges ke liye Bellman-Ford use karo.

🔹 Topological Sort (Kahn's Algorithm – BFS)

DAG (Directed Acyclic Graph) mein nodes ko aise order karo ki agar A→B edge hai toh A, B se pehle aaye. Dependencies resolve karne ke liye!
Example: Course prerequisites, Build systems 
Python
  from collections import deque

  def topoSort(adj, V):
    inDegree = [0] * V
    for u in range(V):
      for v in adj[u]:
        inDegree[v] += 1
    q = deque()
    for i in range(V):
      if inDegree[i] == 0:
        q.append(i)  # no dependency
    order = []
    while q:
      node = q.popleft()
      order.append(node)
      for v in adj[node]:
        inDegree[v] -= 1
        if inDegree[v] == 0:
          q.append(v)
    return order  # size < V matlab cycle hai!

🔹 Union-Find (Disjoint Set) – Cycle Detection

Groups (sets) maintain karta hai. Do nodes ek hi group mein hain? Union-Find O(α) ≈ O(1) mein batata hai! 
Python
  parent = []
  rank = []

  def init(n):
    global parent, rank
    parent = list(range(n))
    rank = [0] * n

  def find(x):  # path compression
    if parent[x] != x:
      parent[x] = find(parent[x])
    return parent[x]

  def union(x, y):  # returns False if cycle
    px, py = find(x), find(y)
    if px == py:
      return False  # already same – cycle!
    if rank[px] < rank[py]:
      parent[px] = py
    elif rank[px] > rank[py]:
      parent[py] = px
    else:
      parent[py] = px
      rank[px] += 1
    return True
Union-Find Kruskal's MST algorithm mein bhi use hota hai – zaroor practice karo!

🏝️ Number of Islands – DFS/BFS on Grid

Python
  def numIslands(grid):
    count = 0
    rows = len(grid)
    cols = len(grid[0]) if rows else 0
    def dfs(i, j):
      if i < 0 or i >= rows or j < 0 or j >= cols or grid[i][j] != '1':
        return
      grid[i][j] = '0'  # visited mark karo
      dfs(i+1, j); dfs(i-1, j); dfs(i, j+1); dfs(i, j-1)
    for i in range(rows):
      for j in range(cols):
        if grid[i][j] == '1':
          dfs(i, j)
          count += 1
    return count
