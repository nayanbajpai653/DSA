1. Array Kya Hota Hai?

Definition, memory layout, aur basic concepts
▼
Array ek contiguous (lagatar) memory mein stored elements ka collection hai jisme same type ka data hota hai. Har element ko ek unique index se access karte hain, jo 0 se shuru hota hai.

🏠 Real Life Example

🏢Sochlo ek building hai jisme flats hain – Flat 0, Flat 1, Flat 2... Saare ek hi building mein hain (contiguous), aur flat number se directly kisi bhi flat mein ja sakte ho!

🔸Har int = 4 bytes — isliye addresses 1000, 1004, 1008... hain
🔸arr[2] ka address = Base Address + (2 × 4) = 1000 + 8 = 1008
🔸Yahi formula hai: Address = Base + (index × size_of_datatype)

📋 Key Properties

✅Fixed Size – ek baar declare karo, size change nahi hota (static arrays mein)
✅Same Datatype – sab elements same type ke hone chahiye
✅Random Access – kisi bhi index pe directly jaao O(1) mein
✅0-indexed – pehla element index 0 pe hota hai
Last valid index = size - 1. Isse bahar jaoge toh Index Out of Bounds error aayega!

4. Types of Arrays

1D, 2D, Multi-D, Static, Dynamic
▼

1D Array (Single Dimensional)

Sabse simple – ek line mein elements. Jaise: [5, 10, 15, 20, 25]
⌛1D array access O(1), traversal O(n), insert/delete middle O(n).

2D Array (Matrix / Grid)

Row aur Column dono hote hain. Sochlo chess board ya Excel sheet.
arr[row][column] se access karo.
⌛2D array access O(1) per element, traversal O(rows * columns), insert/delete O(n) per row shift.
Python
# 3x3 matrix
mat = [
  [1, 2, 3],  # Row 0
  [4, 5, 6],  # Row 1
  [7, 8, 9],  # Row 2
]
print(mat[1][2])  # Output: 6 (Row 1, Col 2)

# Traverse karo
for i in range(3):
  for j in range(3):
    print(mat[i][j], end=' ')

5. Important Array Techniques

Interview mein aane wali techniques – must know!
▼

🔹 Technique 1: Two Pointer

Do pointers maintain karo – ek left se, ek right se. Move karo condition ke hisaab se. O(n) mein O(n²) problems solve ho jaati hain! 
Python
    # Problem: Sorted array mein pair dhundho jiska sum = target
    left, right = 0, len(arr) - 1
    while left < right:
      s = arr[left] + arr[right]
      if s == target:
        print(left, right)
        break
      elif s < target:
        left += 1   # sum badhao
      else:
        right -= 1  # sum ghataao
✅Use karo: Pair sum, Triplet sum, Palindrome check, Remove duplicates from sorted array

🔹 Technique 2: Sliding Window

Ek "window" (subarray) maintain karo. Window ko slide karo – pehle wala element hatao, naya add karo. Baar baar recalculate mat karo! O(n) 
Python
    # Problem: Size k ka maximum sum subarray
    windowSum = sum(arr[:k])
    maxSum = windowSum
    for i in range(k, len(arr)):
      windowSum += arr[i]            # naya element add
      windowSum -= arr[i - k]        # purana element hatao
      maxSum = max(maxSum, windowSum)
    # O(n) mein ho gaya!
✅Use karo: Max sum subarray, Longest substring without repeat, Min window substring

🔹 Technique 3: Prefix Sum

Pehle ek prefix sum array banao. Phir kisi bhi range ka sum O(1) mein nikalo! 
Python
    # Prefix sum array banao
    prefix = [0] * (n + 1)
    for i in range(n):
      prefix[i+1] = prefix[i] + arr[i]

    # Range [l, r] ka sum = prefix[r+1] - prefix[l]
    rangeSum = prefix[r+1] - prefix[l]  # O(1)

🔹 Technique 4: Kadane's Algorithm

Maximum subarray sum nikalne ka classic O(n) algorithm. DP ka simplest example! 
Python
    # Maximum Subarray Sum (Kadane's)
    maxSum = curr = arr[0]
    for x in arr[1:]:
      curr = max(x, curr + x)
      maxSum = max(maxSum, curr)
    # maxSum = answer hai!
Kadane's Algorithm ek classic hai – "agar current sum negative ho jaaye, toh fresh start karo"!

🔹 Technique 5: Dutch National Flag (3-way partition)

Array mein teen types ke elements ko sort karo bina extra space ke. Classic example: 0, 1, 2 sort karo. 
Python
    # Dutch National Flag (0/1/2 sort)
    low, mid, high = 0, 0, len(arr) - 1
    while mid <= high:
      if arr[mid] == 0:
        arr[low], arr[mid] = arr[mid], arr[low]; low += 1; mid += 1
      elif arr[mid] == 1:
        mid += 1
      else:
        arr[mid], arr[high] = arr[high], arr[mid]; high -= 1

6. Common Array Operations (Yaad Karo!)

Reverse, Rotate, Find duplicates, Sort – sab kuch
▼

🔄 Array Reverse Karo

Python
    def reverse(arr):
      l, r = 0, len(arr) - 1
      while l < r:
        arr[l], arr[r] = arr[r], arr[l]
        l += 1; r -= 1  # O(n) time, O(1) space

↩️ Array Rotate karo (k steps left)

Python
    # Rotate left by k using reverses (or simply slices)
    # Using slice: arr = arr[k:] + arr[:k]
    arr = arr[k:] + arr[:k]  # [1,2,3,4,5] with k=2 -> [3,4,5,1,2]

🔢 Duplicates Dhundho

Python
    # HashSet se O(n) mein

🏆 Max & Min Dhundho

Python
    mx = arr[0]; mn = arr[0]
    for x in arr:
      mx = max(mx, x)
      mn = min(mn, x)

🎯 Second Largest Dhundho

Python
    first = second = float('-inf')
    for x in arr:
      if x > first:
        second = first; first = x
      elif x > second and x != first:
        second = x
    # O(n) single pass! Sort mat karo.
Sort karke second largest dhundhna O(n log n) hoga. Upar wala approach O(n) hai – interview mein yahi batao!

🌧️ Trapping Rain Water – Must Know!

Python
    # Trapping Rain Water two-pointer
    left, right = 0, n - 1
    leftMax = rightMax = water = 0
    while left <= right:
      if height[left] <= height[right]:
        if height[left] >= leftMax:
          leftMax = height[left]
        else:
          water += leftMax - height[left]
        left += 1
      else:
        if height[right] >= rightMax:
          rightMax = height[right]
        else:
          water += rightMax - height[right]
        right -= 1
    # O(n) time, O(1) space!
