1. Big-O Notation

Time & Space Complexity – code kitna fast hai?
▼
Kya hai yeh? Big-O notation se hum measure karte hain ki koi algorithm kitna time aur memory leta hai jab input bada hota hai. Isko hum worst-case performance kehte hain.

Common Complexities (Best to Worst)

NotationNaamExampleSpeed
O(1)ConstantArray index access⚡ Best
O(log n)LogarithmicBinary Search✅ Great
O(n)LinearSimple loop👍 OK
O(n log n)LinearithmicMerge Sort🙂 Decent
O(n²)QuadraticBubble Sort🐢 Slow
O(2ⁿ)ExponentialFibonacci (naive)💀 Very Slow
O(1) matlab input chahe kitna bhi bada ho, time same rahega. Jaise array mein arr[5] directly milta hai.
O(n²) loops ke andar loops se aata hai – large inputs pe bohot slow ho jaata hai.

Quick Rules

🔸Ek simple loop = O(n)
🔸Loop ke andar loop = O(n²)
🔸Har step mein half karo = O(log n)
🔸Constants drop karo: O(2n) = O(n)

2. Arrays

Sabse basic data structure – ek line mein data store karo
▼
Kya hai Array? Array ek contiguous memory block hai jisme same type ke elements store hote hain. Index 0 se shuru hota hai. Sochlo jaise ek numbered shelf – box 0, box 1, box 2...

Key Operations & Complexity

OperationTimeNote
Access (arr[i])O(1)Direct index pe jao
Search (unsorted)O(n)Sab elements check karo
Insert at endO(1)Simply add karo
Insert at middleO(n)Saare shift karne padte hain
DeleteO(n)Shift required hai

Important Array Techniques

🔹 Two Pointer Technique

→Do pointers – ek left se, ek right se. Bohot saari problems solve hoti hain isse. Example: sorted array mein pair dhundna jiska sum target ho.
// Two Pointer – Target Sum
int left = 0, right = n - 1;
while (left < right) {
  int sum = arr[left] + arr[right];
  if (sum == target) return true;
  else if (sum < target) left++;
  else right--;
}

🔹 Sliding Window

→Ek fixed ya variable size ka window maintain karo. Maximum subarray sum, longest substring – sab mein kaam aata hai.
Array questions mein pehle sorted hai ya nahi check karo – isse approach badal jaati hai!

3. Linked List

Nodes ki chain – ek node doosre ko point karta hai
▼
Kya hai? Linked List mein Nodes hote hain. Har node mein data hota hai aur ek pointer jo next node ko point karta hai. Array ki tarah contiguous memory nahi chahiye.

[ 10 | → ] → [ 20 | → ] → [ 30 | NULL ]

Types

1️⃣Singly Linked List – sirf next pointer. Ek direction mein chalo.
2️⃣Doubly Linked List – prev aur next dono pointers. Dono taraf ja sakte ho.
🔄Circular Linked List – last node phir se first ko point karta hai.
⌛Singly: search O(n), head insert O(1). Doubly: insert/delete known position O(1). Circular: similar, tail operations O(1) with tail pointer.

Operations & Complexity

OperationTime
Access (kth element)O(n)
Insert at headO(1)
Insert at tailO(n) or O(1)*
Delete nodeO(n)
SearchO(n)

Important Problems

🔸Cycle detect karo – Floyd's Algorithm (slow & fast pointer)
🔸Reverse karo – 3 pointers: prev, curr, next
🔸Middle dhundho – slow/fast pointer (slow 1 step, fast 2 steps)
// Reverse Linked List
Node* prev = NULL, *curr = head, *next;
while (curr != NULL) {
  next = curr->next;
  curr->next = prev;
  prev = curr;
  curr = next;
}
head = prev;
Array vs LinkedList: Array fast access deta hai, LinkedList fast insert/delete karta hai beginning mein.

4. Stack & Queue

LIFO aur FIFO – real life jaisi structures
▼

Stack – LIFO (Last In, First Out)

Sochlo ek plate ki stack – jo plate upar se daali, wahi pehle nikalti hai. Push = daalo, Pop = nikalo.
✅Uses: Undo/Redo, Browser back button, Balanced parentheses check, Function call stack
⚡Push, Pop, Peek – sab O(1)
// Stack in Java
Stack<Integer> st = new Stack<>();
st.push(10);   // daalo
st.pop();     // nikalo
st.peek();    // dekho, nikalo nahi

Queue – FIFO (First In, First Out)

Sochlo bus ki line – jo pehle aaya, woh pehle jaayega. Enqueue = add, Dequeue = remove.
✅Uses: BFS traversal, Printer queue, CPU scheduling, Level-order tree traversal
// Queue in Java
Queue<Integer> q = new LinkedList<>();
q.offer(10);   // add karo
q.poll();     // front se nikalo
q.peek();     // front dekho

Deque (Double Ended Queue)

🔸Dono ends se add aur remove kar sakte ho. Sliding window maximum problem mein kaam aata hai.
Monotonic Stack yaad rakho – stock price problems, NGE (Next Greater Element) ke liye super useful hai!
🗂️

5. Hashing (HashMap / HashSet)

O(1) mein dhundho – magic structure!
▼
Kya hai? HashMap ek key-value store hai. Key se directly value milti hai – jaise dictionary mein word se definition milti hai. Hash function key ko index mein convert karta hai.

HashMap vs HashSet

📗HashMap – key → value pairs store karta hai. Example: naam → phone number
📘HashSet – sirf unique values store karta hai. Duplicates nahi.

Complexity

OperationAverageWorst (collision)
InsertO(1)O(n)
SearchO(1)O(n)
DeleteO(1)O(n)
// HashMap – frequency count
HashMap<Integer, Integer> map = new HashMap<>();
for (int x : arr)
  map.put(x, map.getOrDefault(x, 0) + 1);
// Ab har element ki count hai O(1) mein!

Common Uses

🔸Two Sum problem – pair dhundna
🔸Frequency counting – kaunsa element kitni baar aaya
🔸Anagram check – dono strings ke chars same hain?
🔸Duplicate dhundna array mein
Jab bhi O(1) lookup chahiye, pehle HashMap sochna!

6. Trees (Binary Tree & BST)

Hierarchical structure – parent aur child nodes
▼
Tree kya hai? Ek hierarchical data structure jisme ek root node hota hai aur usse neeche child nodes. Har node ke max 2 children ho sakte hain (Binary Tree mein).

Key Terms

🔸Root – sabse upar wala node
🔸Leaf – jiske koi children nahi
🔸Height – root se deepest leaf tak ki depth
🔸BST Rule – Left < Root < Right (hamesha!)

Tree Traversals

TraversalOrderUse Case
InorderLeft → Root → RightBST mein sorted order milta hai
PreorderRoot → Left → RightTree copy karna
PostorderLeft → Right → RootTree delete karna
Level OrderLevel by level (BFS)Shortest path, level-wise print
// Inorder Traversal (Recursive)
void inorder(Node* root) {
  if (root == NULL) return;
  inorder(root->left);   // left jaao
  cout << root->val;    // print karo
  inorder(root->right);  // right jaao
}

BST Operations

OperationAverageWorst (skewed)
SearchO(log n)O(n)
InsertO(log n)O(n)
DeleteO(log n)O(n)
Binary Search Tree mein Inorder traversal karo – sorted array milega! Yeh ek classic interview question hai.

7. Graphs

Nodes aur Edges – connections ka network
▼
Graph kya hai? Vertices (nodes) aur Edges (connections) ka collection. Real life mein – social network, maps, internet – sab graphs hain!

Types of Graphs

🔸Undirected – edges dono direction mein (friendship)
🔸Directed (Digraph) – edges ek hi direction mein (Instagram follow)
🔸Weighted – edges pe cost/weight hota hai (GPS routes)
🔸Cyclic / Acyclic – cycle hai ya nahi
⌛Graph traversal time mostly O(V + E) with adjacency list. Adjacency matrix can cost O(V²) in dense graphs.

Representation

📊Adjacency Matrix – 2D array, O(V²) space. Dense graphs ke liye.
📋Adjacency List – Array of lists, O(V+E) space. Sparse graphs ke liye. Zyada use hota hai!

Graph Traversals

🔹 BFS (Breadth First Search) – Level by Level

→Queue use karta hai. Shortest path (unweighted) ke liye best hai.
// BFS
Queue<Integer> q; q.push(start);
visited[start] = true;
while (!q.empty()) {
  int node = q.front(); q.pop();
  for (int neighbor : adj[node])
    if (!visited[neighbor]) {
      visited[neighbor] = true;
      q.push(neighbor);
    }
}

🔹 DFS (Depth First Search) – Deep jaao

→Stack / Recursion use karta hai. Cycle detection, connected components ke liye.

Important Algorithms

🗺️Dijkstra's – Weighted graph mein shortest path. Priority Queue use karta hai. O((V+E) log V)
🌲Kruskal's / Prim's – Minimum Spanning Tree (MST)
🔄Topological Sort – DAG (Directed Acyclic Graph) mein dependencies ka order
Cycle detection important hai – DFS se directed graphs mein, Union-Find se undirected mein.

Merge Sort – Divide & Conquer

// Array ko do halves mein baanto
// Dono ko sort karo recursively
// Phir merge karo
mergeSort(arr, 0, n-1):
  mid = (l+r)/2
  mergeSort(arr, l, mid)
  mergeSort(arr, mid+1, r)
  merge(arr, l, mid, r)  // O(n)
Production code mein languages built-in sort use karta hai jo usually Timsort hai (Merge + Insertion ka combination).

9. Searching Algorithms

Data mein element dhundho efficiently
▼

Linear Search

Ek ek element check karo. O(n). Unsorted array ke liye yahi option hai.

Binary Search ⚡

Sorted array mein hi kaam karta hai! Har step mein search space half ho jaata hai – isliye O(log n). 1 billion elements mein sirf ~30 steps! 
int binarySearch(int[] arr, int target) {
  int low = 0, high = arr.length - 1;
  while (low <= high) {
    int mid = low + (high - low) / 2;
    if (arr[mid] == target) return mid;
    else if (arr[mid] < target) low = mid + 1;
    else high = mid - 1;
  }
  return -1; // nahi mila
}

Binary Search Applications

🔸Sorted array mein element dhundna
🔸First / Last occurrence dhundna
🔸"Answer pe Binary Search" – minimum/maximum value dhundna jisme condition satisfy ho
🔸Square root find karna
mid = (low + high)/2 mat likho – integer overflow ho sakta hai! mid = low + (high-low)/2 use karo.

10. Recursion & Dynamic Programming

Problem ko chhote parts mein todo aur reuse karo
▼

Recursion

Function khud apne aap ko call karta hai! Har recursion mein do cheezein honi chahiye:
1. Base Case – kab rukna hai
2. Recursive Case – chota problem banao 
// Factorial – N! = N × (N-1)!
int fact(int n) {
  if (n == 0) return 1;  // Base case
  return n * fact(n-1);   // Recursive case
}

Dynamic Programming (DP)

DP = Recursion + Memoization. Ek hi subproblem baar baar solve karne ki jagah, answer store karke reuse karo.

🔹 Two Approaches

1️⃣Top-Down (Memoization) – Recursion + HashMap mein results store karo
2️⃣Bottom-Up (Tabulation) – Chhote problems pehle solve karo, bade ke liye use karo
// Fibonacci – Naive: O(2ⁿ), DP: O(n)

// Memoization (Top-Down)
int[] memo = new int[n+1];
int fib(int n) {
  if (n <= 1) return n;
  if (memo[n] != 0) return memo[n]; // cache!
  return memo[n] = fib(n-1) + fib(n-2);
}

// Tabulation (Bottom-Up)
dp[0] = 0; dp[1] = 1;
for (int i=2; i<=n; i++)
  dp[i] = dp[i-1] + dp[i-2];

Classic DP Problems

🎒0/1 Knapsack – items le ya mat le, max value nikalo
🔤Longest Common Subsequence (LCS) – do strings mein common subsequence
📈Longest Increasing Subsequence (LIS)
🪙Coin Change – minimum coins se amount banana
📐Matrix Chain Multiplication, Edit Distance
DP problem identify kaise karein? Agar problem overlapping subproblems aur optimal substructure dono hain – toh DP lagao!
Pehle recursion samjho phir DP optimize karo. Direct DP mat socho – confused ho jaoge!
