1. Recursion – Basics

Function khud ko call kare – Base Case + Recursive Case
▼
Recursion = function jo apne aap ko call kare. Do cheezein zaroor honi chahiye:
1. Base Case – kab rukna hai (warna infinite loop!)
2. Recursive Case – problem ko chhhota karo aur apne aap ko call karo

Classic Example – Factorial

Python
  # n! = n × (n-1) × (n-2) × ... × 1
  def factorial(n):
    if n == 0 or n == 1:
      return 1  # Base Case – RUK JAO!
    return n * factorial(n - 1)  # Recursive Case
  # factorial(4) = 4 × factorial(3) = 24 ✅

Call Stack – Memory mein kya hota hai?

factorial(4) → calls factorial(3)
  factorial(3) → calls factorial(2)
    factorial(2) → calls factorial(1)
      factorial(1) → returns 1 (Base Case!)
    factorial(2) returns 2×1 = 2
  factorial(3) returns 3×2 = 6
factorial(4) returns 4×6 = 24

3 Rules of Recursion

1️⃣Base Case pehle likho – bina iske infinite recursion hogi
2️⃣Problem chhhota karte jao – har call mein input size ghato
3️⃣Recursion pe trust karo – assume karo chhoti problem solve ho gayi
Stack Overflow! Agar base case galat ho ya recursion bahut deep ho jaaye toh Stack Overflow Exception aayega. Default stack ~10,000 calls handle kar sakta hai.

More Examples

Python
  # Fibonacci (naive)
  def fib(n):
    if n <= 1:
      return n
    return fib(n-1) + fib(n-2)  # O(2ⁿ) – bahut slow!

  # Power function – fast exponentiation
  def power(x, n):
    if n == 0:
      return 1
    if n % 2 == 0:  # Even power – fast exponentiation
      half = power(x, n//2)
      return half * half
    return x * power(x, n-1)  # O(log n)

2. Backtracking

Try karo, galat laga? Wapas aao aur doosra try karo
▼
Backtracking ek special recursion hai jisme hum ek path follow karte hain. Agar dead end mile toh backtrack karo (undo last choice) aur doosra path try karo.

🧩 Maze solve karna – ek direction mein jao, band gali mile toh wapas aao!

Template – Backtracking

Python
  def backtrack(state, choices):
    if goal_reached(state):
      result.append(list(state))  # answer store karo
      return
    for choice in choices:
      state.append(choice)             # choose
      backtrack(state, remaining)      # explore
      state.pop()                      # un-choose (BACKTRACK!)

🔹 Problem: Subsets

Python
  def subsets(nums):
    res = []
    def backtrack(curr, start):
      res.append(list(curr))  # har state ek subset hai
      for i in range(start, len(nums)):
        curr.append(nums[i])            # choose
        backtrack(curr, i+1)            # explore
        curr.pop()                      # un-choose
    backtrack([], 0)
    return res

🔹 N-Queens Problem

Python
  def solve(row, board, n):
    if row == n:
      addSolution(board)
      return
    for col in range(n):
      if isSafe(board, row, col):
        board[row] = col         # queen rakho
        solve(row+1, board, n)   # agli row
        board[row] = -1          # backtrack!
Backtracking problems: Subsets, Permutations, Combinations, N-Queens, Sudoku Solver – sab same template se solve hote hain!

3. Dynamic Programming – Introduction

Recursion + Caching = DP. Ek baar solve, baar baar use!
▼
DP = Recursion + Memoization. Ek hi subproblem baar baar solve karne ki jagah, answer store (cache) karo aur reuse karo.

DP use karo jab problem mein:
1. Overlapping Subproblems – same subproblem baar baar aata hai
2. Optimal Substructure – optimal solution smaller optimal solutions se banta hai

Fibonacci – Naive vs DP

Naive Recursion – O(2ⁿ) 😱

fib(5)
  fib(4)                  fib(3)
    fib(3)      fib(2)    fib(2) ← REPEAT! fib(1)
      fib(2) ← REPEAT! fib(1)
Bahut saare repeated calls → O(2ⁿ) exponential!

With Memoization – O(n) 🚀

fib(5) calls fib(4) aur fib(3)
fib(4) calls fib(3) aur fib(2)
fib(3) calls fib(2) aur fib(1)
fib(2) – CACHED → direct return!
fib(3) – CACHED → direct return!
Total calls: sirf n → O(n)! 
Python – Top-Down (Memoization)
  memo = {}
  def fib(n):
    if n <= 1:
      return n
    if n in memo:
      return memo[n]  # Cache hit!
    memo[n] = fib(n-1) + fib(n-2)
    return memo[n]
  
Python – Bottom-Up (Tabulation)
  def fib_tab(n):
    if n <= 1:
      return n
    dp = [0] * (n+1)
    dp[0], dp[1] = 0, 1
    for i in range(2, n+1):
      dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
  # Space Optimized: sirf 2 variables chahiye!
  def fib_space_opt(n):
    if n <= 1:
      return n
    a, b = 0, 1
    for _ in range(2, n+1):
      a, b = b, a + b
    return b
ApproachTimeSpaceStyle
Naive RecursionO(2ⁿ)O(n)Simple but slow
Top-Down (Memo)O(n)O(n)Recursion + cache
Bottom-Up (Tab)O(n)O(1)*Iterative, no stack
*Space optimized version mein. General tabulation O(n) space leta hai.

🔹 1. 0/1 Knapsack

N items hain, har ek ka weight aur value hai. Bag ki capacity W hai. Maximum value kaise lo? Har item ya toh lo (1) ya chhodo (0). 
Python – Bottom-Up DP
  def knapsack(wt, val, W, n):
    dp = [[0] * (W+1) for _ in range(n+1)]
    for i in range(1, n+1):
      for w in range(W+1):
        # Item include mat karo
        dp[i][w] = dp[i-1][w]
        # Item include karo (agar fit hota hai)
        if wt[i-1] <= w:
          dp[i][w] = max(dp[i][w], val[i-1] + dp[i-1][w-wt[i-1]])
    return dp[n][W]
  # Time: O(n×W) | Space: O(n×W)

🔹 2. Longest Common Subsequence (LCS)

Do strings ka longest common subsequence dhundho. "ABCBDAB" aur "BDCAB" ka LCS = "BCAB" (length 4). 
Python
  def lcs(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n+1) for _ in range(m+1)]
    for i in range(1, m+1):
      for j in range(1, n+1):
        if s1[i-1] == s2[j-1]:
          dp[i][j] = 1 + dp[i-1][j-1]  # match!
        else:
          dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]

🔹 3. Longest Increasing Subsequence (LIS)

Python – O(n²) DP
  def lis(nums):
    n = len(nums)
    if n == 0: return 0
    dp = [1] * n  # har element ka LIS min = 1
    for i in range(1, n):
      for j in range(i):
        if nums[j] < nums[i]:
          dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
  # [10,9,2,5,3,7,101,18] → LIS = 4 → [2,3,7,101]

🔹 4. Coin Change – Minimum Coins

Python
  def coinChange(coins, amount):
    dp = [amount + 1] * (amount + 1)  # infinity se initialize
    dp[0] = 0
    for i in range(1, amount + 1):
      for coin in coins:
        if coin <= i:
          dp[i] = min(dp[i], dp[i-coin] + 1)
    return -1 if dp[amount] > amount else dp[amount]
  # coins=[1,5,6,9], amount=11 → 2 coins (5+6)

🔹 5. Edit Distance (Levenshtein)

Python
  def editDistance(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n+1) for _ in range(m+1)]
    for i in range(m+1):
      dp[i][0] = i
    for j in range(n+1):
      dp[0][j] = j
    for i in range(1, m+1):
      for j in range(1, n+1):
        if s1[i-1] == s2[j-1]:
          dp[i][j] = dp[i-1][j-1]
        else:
          dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])
    return dp[m][n]
DP mein pehle recurrence relation dhundho – "dp[i] kaise dp[i-1] se banta hai?" Yeh samajh aa gaya toh code likhna aasaan hai!

🔹 Pattern: House Robber (1D DP)

Python
  # Adjacent ghar nahi loot sakte – max money?
  def rob(nums):
    prev2, prev1 = 0, 0
    for num in nums:
      curr = max(prev1, prev2 + num)
      prev2, prev1 = prev1, curr
    return prev1  # O(n) time, O(1) space!

🔹 Pattern: Unique Paths (2D Grid DP)

Python
  # m×n grid mein top-left se bottom-right – kitne paths?
  def uniquePaths(m, n):
    dp = [[0] * n for _ in range(m)]
    for i in range(m):
      dp[i][0] = 1  # left column
    for j in range(n):
      dp[0][j] = 1  # top row
    for i in range(1, m):
      for j in range(1, n):
        dp[i][j] = dp[i-1][j] + dp[i][j-1]  # from top+left
    return dp[m-1][n-1]
