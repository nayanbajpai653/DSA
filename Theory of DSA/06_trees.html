2. Tree Traversals – 4 Types

Inorder, Preorder, Postorder, Level Order – code ke saath
▼
Tree traverse karna matlab har node ko ek baar visit karna. Alag-alag order mein karo toh alag results milte hain!
Example tree: 1(2(4,5), 3(6,7))
⌛Har traversal type O(n) time leta hai kyunki har node ek baar visit hoti hai. Level order bhi O(n) hi hai.

🔹 Inorder – Left → Root → Right

📌Result: 4 → 2 → 5 → 1 → 6 → 3 → 7 | BST mein yeh sorted order deta hai!
Python
  def inorder(root):
    if not root:
      return
    inorder(root.left)            # Left subtree
    print(root.val, end=' ')      # Root
    inorder(root.right)           # Right subtree

🔹 Preorder – Root → Left → Right

📌Result: 1 → 2 → 4 → 5 → 3 → 6 → 7 | Tree copy karne mein useful
Python
  def preorder(root):
    if not root:
      return
    print(root.val, end=' ')  # Root pehle
    preorder(root.left)
    preorder(root.right)

🔹 Postorder – Left → Right → Root

📌Result: 4 → 5 → 2 → 6 → 7 → 3 → 1 | Tree delete karne mein / expression evaluation
Python
  def postorder(root):
    if not root:
      return
    postorder(root.left)
    postorder(root.right)
    print(root.val, end=' ')  # Root last mein

🔹 Level Order (BFS) – Level by Level

📌Result: 1 → 2 3 → 4 5 6 7 | Queue use hota hai. Shortest path, level-wise problems.
Python
  from collections import deque

  def levelOrder(root):
    res = []
    if not root:
      return res
    q = deque([root])
    while q:
      size = len(q)
      level = []
      for _ in range(size):
        node = q.popleft()
        level.append(node.val)
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)
      res.append(level)
    return res
BST mein Inorder = Sorted Array! Yeh fact 50+ problems mein kaam aata hai.

3. Binary Search Tree (BST)

Left < Root < Right – O(log n) search
▼
BST ek special Binary Tree hai jisme har node ke liye:
• Left subtree ke saare values < node value
• Right subtree ke saare values > node value

Yeh rule recursively har node pe apply hota hai!

Visual – BST Example

BST Operations

Python
  def search(root, key):
    if not root or root.val == key:
      return root
    if key < root.val:
      return search(root.left, key)
    return search(root.right, key)

  def insert(root, val):
    if not root:
      return TreeNode(val)
    if val < root.val:
      root.left = insert(root.left, val)
    else:
      root.right = insert(root.right, val)
    return root
OperationAverage (Balanced)Worst (Skewed)
SearchO(log n)O(n)
InsertO(log n)O(n)
DeleteO(log n)O(n)
Agar BST skewed ho jaaye (e.g., sorted order mein insert karo) toh height O(n) ho jaati hai – essentially ek linked list ban jaata hai! Isliye AVL ya Red-Black Tree use karte hain.

4. Important Tree Problems

Height, Diameter, LCA, Path Sum – code ke saath
▼

🔹 1. Height of Tree

Python
  def height(root):
    if not root:
      return 0
    return 1 + max(height(root.left), height(root.right))

🔹 2. Diameter of Binary Tree

🔸Longest path between any two nodes. Har node pe: leftHeight + rightHeight. Max woh answer hai!
Python
  def diameter(root):
    maxDia = 0
    def dfs(node):
      nonlocal maxDia
      if not node:
        return 0
      L = dfs(node.left)
      R = dfs(node.right)
      maxDia = max(maxDia, L + R)
      return 1 + max(L, R)
    dfs(root)
    return maxDia

🔹 3. Lowest Common Ancestor (LCA)

Python
  def lca(root, p, q):
    if not root or root == p or root == q:
      return root
    left = lca(root.left, p, q)
    right = lca(root.right, p, q)
    if left and right:
      return root  # dono sides mein mile
    return left if left else right

🔹 4. Check Balanced Tree

Python
  def isBalanced(root):
    def checkHeight(node):
      if not node:
        return 0
      L = checkHeight(node.left)
      if L == -1: return -1
      R = checkHeight(node.right)
      if R == -1: return -1
      if abs(L - R) > 1: return -1
      return 1 + max(L, R)
    return checkHeight(root) != -1

🔹 5. Path Sum

Python
  def hasPathSum(root, target):
    if not root:
      return False
    if not root.left and not root.right:
      return root.val == target
    return hasPathSum(root.left, target - root.val) or hasPathSum(root.right, target - root.val)

🔹 6. Validate BST

Python
  def isValidBST(root):
    def validate(node, low, high):
      if not node:
        return True
      if not (low < node.val < high):
        return False
      return validate(node.left, low, node.val) and validate(node.right, node.val, high)
    return validate(root, float('-inf'), float('inf'))
Tree problems mein zyada tar recursion use hoti hai. Base case = null node, phir left aur right recursively solve karo!

5. Special Trees – AVL, Red-Black, B-Tree, Heap, Trie

Advanced trees – jab BST kafi nahi hota
▼

AVL Tree (Self-Balancing BST)

AVL tree automatically balanced rehta hai – har node ke liye |leftHeight - rightHeight| ≤ 1. Guaranteed O(log n) operations!
🔸Rotations (Left/Right/LeftRight/RightLeft) se balance maintain karta hai
🔸Stricter balance than Red-Black, lekin zyada rotations hote hain

Red-Black Tree (Self-Balancing BST)

Color property wala BST! Har node ke paas ek color hota hai – Red ya Black. Balance maintain karta hai:
Properties:
1. Root hamesha Black
2. Null nodes Black maane jaate hain
3. Red node ke children hamesha Black (no two reds in a row)
4. Root se har path mein Black nodes ki count same honi chahiye
🔸Insert/Delete/Search: O(log n) guaranteed
🔸Used in: Java TreeMap, C++ std::map, Linux kernel
🔸Zyada flexible hai AVL se – rotations kam hote hain, recoloring zyada

Visual – Red-Black Tree

Python
  # Red-Black Tree insertion
  class RBNode:
    def __init__(self, val):
      self.val = val
      self.color = "RED"  # naya node hamesha red
      self.left = None
      self.right = None
      self.parent = None
  
  # Insert ke baad 3 cases check karo:
  # Case 1: Uncle red → recolor karo
  # Case 2: Uncle black (triangle) → rotate karo
  # Case 3: Uncle black (line) → rotate + recolor karo

B-Tree (Multi-way Search Tree)

Database aur File Systems mein king! Ek node mein multiple keys aur children rakh sakta hai.
Properties (degree m):
• Har node mein max m children (min ⌈m/2⌉)
• Har node mein max m-1 keys
• Root mein min 1 key
• Saare leaves same level pe hain
• Keys sorted order mein
🔸Disk I/O reduce karte hain kyunki ek node mein bohat sare keys
🔸Search/Insert/Delete: O(log n)
🔸Used in: MySQL, PostgreSQL indices, file systems (NTFS, ext4)

Visual – B-Tree (Degree 3)

Python
  # B-Tree Node
  class BNode:
    def __init__(self, leaf=True):
      self.keys = []        # max m-1 keys
      self.children = []    # max m children
      self.leaf = leaf
  
  # Insert mein agar node full (m-1 keys) ho toh split karo
  # Search simple hai: linear search keys, phir appropriate child ko go karo

B+ Tree (Enhanced B-Tree)

B-Tree ka advanced version! Database mein sabse zyada use hota hai.
Key Difference:
• Internal nodes sirf routing ke liye (keys store karte hain)
• Actual data/values sirf leaf nodes mein
• Saare leaf nodes ek linked list se connected hote hain
• Range queries superfast ban jaati hain!
🔸Insert/Delete/Search: O(log n)
🔸Used in: Almost all relational databases (MySQL, PostgreSQL, Oracle)
🔸B-Tree se better kyunki range queries (SELECT ... WHERE age BETWEEN 20 AND 30) leaf nodes ke through fast ho jaati hain

Visual – B+ Tree

Python
  # B+ Tree – Internal vs Leaf nodes
  class BPNode:
    def __init__(self, leaf=True):
      if leaf:
        self.data = []        # actual values
        self.next = None      # linked list pointer
      else:
        self.keys = []        # routing keys only
        self.children = []
  
  # Range query "30-80":
  # 1. Internal nodes se traverse → leaf node par pahunch
  # 2. Leaf ke linked list se walk karo → all values in range!
  # 3. B-Tree se zyada better kyunki sirf leaves traverse karte ho

    
Heap (Min/Max)

    

      Complete Binary Tree jisme parent hamesha child se chhota (Min-Heap) ya bada (Max-Heap) hota hai. Array mein store hota hai!

      • Parent of i = (i-1)/2

      • Left child = 2*i + 1

      • Right child = 2*i + 2
    

    
🔸Insert: O(log n) | Extract Min/Max: O(log n) | Peek: O(1)

    
🔸Java mein: PriorityQueue = Min-Heap by default


    
Trie (Prefix Tree)

    

      Strings store karne ke liye specialized tree. Har node ek character represent karta hai. Auto-complete, spell check, word search mein use hota hai.
    

    
Python
  class TrieNode:
    def __init__(self):
      self.children = [None] * 26
      self.isEnd = False
  # "cat", "car", "card" insert karo
  # c→a→t(end), c→a→r(end)→d(end)
  # "ca" prefix ke saare words O(m) mein milenge!
