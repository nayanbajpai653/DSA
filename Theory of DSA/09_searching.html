1. Linear Search

Ek ek check karo – Simple par O(n)
▼
Array mein ek ek element check karo jab tak target na mile. Unsorted ya small arrays ke liye theek hai. Koi precondition nahi chahiye! 
Python
  def linearSearch(arr, target):
    for i, val in enumerate(arr):
      if val == target:
        return i  # index return karo
    return -1  # nahi mila
  # Time: O(n) | Space: O(1)
CaseTimeWhen
BestO(1)Target pehle index pe ho
AverageO(n/2)Target middle mein ho
WorstO(n)Target last mein ya nahi ho
✅Unsorted arrays mein use karo
✅Linked List mein (random access nahi)
✅Small arrays (n < 50) ke liye binary se better (overhead nahi)

Binary Search Template (Iterative)

Python
  def binarySearch(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
      mid = low + (high - low) // 2  # overflow-safe
      if arr[mid] == target:
        return mid
      elif arr[mid] < target:
        low = mid + 1
      else:
        high = mid - 1
    return -1  # nahi mila
  # Time: O(log n) | Space: O(1)
mid = (low+high)/2 mat likho – integer overflow ho sakta hai jab low+high > Integer.MAX_VALUE! Hamesha low + (high-low)/2 use karo.

Recursive Version

Python
  def bsRecursive(arr, low, high, target):
    if low > high:
      return -1
    mid = low + (high - low) // 2
    if arr[mid] == target:
      return mid
    if arr[mid] < target:
      return bsRecursive(arr, mid+1, high, target)
    return bsRecursive(arr, low, mid-1, target)
  # Space: O(log n) – recursion stack

3. Binary Search Variations – Must Know!

First/Last occurrence, Lower/Upper bound – sab patterns
▼

🔹 First Occurrence (Lower Bound)

Target ki pehli position – duplicates mein bhi kaam karta hai. Match milne ke baad bhi left jaate raho! 
Python
  def firstOccurrence(arr, target):
    low, high, result = 0, len(arr)-1, -1
    while low <= high:
      mid = low + (high - low) // 2
      if arr[mid] == target:
        result = mid
        high = mid - 1  # phir bhi left jao
      elif arr[mid] < target:
        low = mid + 1
      else:
        high = mid - 1
    return result
  # [1,2,2,2,3,4] target=2 → returns index 1

🔹 Last Occurrence (Upper Bound)

Python
  def lastOccurrence(arr, target):
    low, high, result = 0, len(arr)-1, -1
    while low <= high:
      mid = low + (high - low) // 2
      if arr[mid] == target:
        result = mid
        low = mid + 1  # phir bhi right jao
      elif arr[mid] < target:
        low = mid + 1
      else:
        high = mid - 1
    return result
  # [1,2,2,2,3,4] target=2 → returns index 3

🔹 Count of Element in Sorted Array

Python
  def countOccurrences(arr, target):
    first = firstOccurrence(arr, target)
    if first == -1:
      return 0
    return lastOccurrence(arr, target) - first + 1
  # O(log n) – linear scan se better!

🔹 Search in Rotated Sorted Array

Array sorted tha, phir rotate ho gaya. Example: [4,5,6,7,0,1,2]. Binary search apply karo – ek half hamesha sorted hogi! 
Python
  def searchRotated(arr, target):
    low, high = 0, len(arr)-1
    while low <= high:
      mid = low + (high - low) // 2
      if arr[mid] == target:
        return mid
      # Left half sorted?
      if arr[low] <= arr[mid]:
        if arr[low] <= target < arr[mid]:
          high = mid - 1
        else:
          low = mid + 1
      else:  # Right half sorted
        if arr[mid] < target <= arr[high]:
          low = mid + 1
        else:
          high = mid - 1
    return -1
Rotated array mein hamesha pehle check karo "kaun si half sorted hai" – phir decide karo kahan jaana hai!

4. Binary Search on Answer ⭐

Array pe nahi, Answer Space pe – Advanced Trick!
▼
Concept: Kuch problems mein hum answer ki range pe Binary Search apply kar sakte hain. Yeh tab use hota hai jab:
1. Answer ek range mein hota hai (min to max)
2. Ek monotonic condition hoti hai – "agar X possible hai toh X-1 bhi possible hai" (ya ulta)

🔹 Problem: Koko Eating Bananas

📌Koko bananas khaa rahi hai at speed k/hour. Minimum k dhundho jisme woh h hours mein saare bananas khaa sake.
Python
  def minEatingSpeed(piles, h):
    low, high = 1, max(piles)
    while low < high:
      mid = low + (high - low) // 2
      if canFinish(piles, mid, h):
        high = mid  # try smaller
      else:
        low = mid + 1
    return low

  def canFinish(piles, k, h):
    hours = 0
    for p in piles:
      hours += (p + k - 1) // k  # ceil division
    return hours <= h

🔹 Problem: Find Peak Element

Python
  def findPeakElement(nums):
    low, high = 0, len(nums) - 1
    while low < high:
      mid = low + (high - low) // 2
      if nums[mid] > nums[mid+1]:
        high = mid  # peak left mein
      else:
        low = mid + 1  # peak right mein
    return low

🔹 Sqrt(x) using Binary Search

Python
  def mySqrt(x):
    if x < 2:
      return x
    low, high, ans = 1, x // 2, 1
    while low <= high:
      mid = (low + high) // 2
      if mid * mid == x:
        return mid
      if mid * mid < x:
        ans = mid; low = mid + 1
      else:
        high = mid - 1
    return ans
Binary Search on Answer identify kaise karein? Agar problem "minimum X dhundho jisme condition satisfy ho" ya "maximum X dhundho" type hai – toh BS on Answer use karo!

5. Other Searching Techniques

Jump Search, Interpolation, Ternary Search
▼

🔹 Jump Search – O(√n)

√n steps jump karo, phir backward linear search. Binary se simple implement karna, sorted arrays ke liye. 
Python
  import math
  def jumpSearch(arr, target):
    n = len(arr)
    step = int(math.sqrt(n))
    prev = 0
    while arr[min(step, n) - 1] < target:
      prev = step
      step += int(math.sqrt(n))
      if prev >= n:
        return -1
    while prev < min(step, n) and arr[prev] < target:
      prev += 1
      if prev == min(step, n):
        return -1
    return prev if arr[prev] == target else -1

🔹 Ternary Search – O(log₃n)

Array ko teen parts mein baanto. Unimodal functions (pehle badhte hain phir ghatate hain) mein maximum dhundhne ke liye!
Binary se thoda slow, lekin specific problems mein useful. 
Python
  def ternarySearch(arr, l, r):
    if r <= l:
      return l
    m1 = l + (r - l) // 3
    m2 = r - (r - l) // 3
    if arr[m1] < arr[m2]:
      return ternarySearch(arr, m1+1, r)
    return ternarySearch(arr, l, m2-1)
