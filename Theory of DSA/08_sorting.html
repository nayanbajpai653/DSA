1. Bubble Sort

Adjacent elements compare karo aur swap karo – O(n²)
▼
Har pass mein adjacent elements compare hote hain. Bada element right ki taraf "bubble up" karta hai. N-1 passes mein sort ho jaata hai.

Example: [64, 34, 25, 12, 22]

64
34
25
12
22

Pass 1: 64 sabse right mein bubble up karega → [34,25,12,22,64]

Python
  def bubbleSort(arr):
    n = len(arr)
    for i in range(n-1):
      swapped = False
      for j in range(n-i-1):
        if arr[j] > arr[j+1]:
          arr[j], arr[j+1] = arr[j+1], arr[j]
          swapped = True
      if not swapped:
        break  # Already sorted! O(n) best case
✅Simple to understand, in-place, stable
❌O(n²) average/worst – real use mein avoid karo
🎯

2. Selection Sort

Minimum element dhundho aur sahi jagah rakho – O(n²)
▼
Har pass mein unsorted part ka minimum element dhundho aur pehle position pe rakho. N-1 passes chahiye. 
Python
  def selectionSort(arr):
    n = len(arr)
    for i in range(n-1):
      minIdx = i
      for j in range(i+1, n):
        if arr[j] < arr[minIdx]:
          minIdx = j
      arr[i], arr[minIdx] = arr[minIdx], arr[i]
  # [64,25,12,22,11] → [11,25,12,22,64] (1st pass)
✅Minimum swaps (O(n)) – swap cost zyada hone pe useful
❌Always O(n²) – even if sorted. Not stable.
🃏

3. Insertion Sort

Cards sort karne ki tarah – O(n) best case!
▼
Cards ki tarah – left side sorted rakhte hain, naya element sahi jagah insert karo. Already sorted array mein O(n)!
🃏 Sochlo: Haath mein cards ko sorted order mein rakhna 
Python
  def insertionSort(arr):
    n = len(arr)
    for i in range(1, n):
      key = arr[i]
      j = i - 1
      while j >= 0 and arr[j] > key:
        arr[j+1] = arr[j]
        j -= 1
      arr[j+1] = key
  # [5,1,4,2,8] example
✅Nearly sorted data pe O(n) – best in class
✅Online sort – ek ek element aane pe sort karo
✅Small arrays ke liye preferred (real libraries bhi yahi use karti hain <10 elements ke liye)
🔀

4. Merge Sort ⭐

Divide & Conquer – Guaranteed O(n log n), Stable
▼
Array ko do halves mein baanto → dono ko recursively sort karo → merge karo. Divide & Conquer ka classic example!

Guaranteed O(n log n) – worst case bhi. Stable sort. Extra space chahiye O(n).

Visual Breakdown

[38, 27, 43, 3, 9, 82, 10]
↓ Split
[38,27,43,3]     [9,82,10]
↓ Split again...
[38,27] [43,3] [9,82] [10]
↓ Merge sorted pairs
[27,38] [3,43] [9,82] [10]
↓ Merge again
[3,27,38,43] [9,10,82]
↓ Final merge
[3, 9, 10, 27, 38, 43, 82] ✅ 
Python
  def mergeSort(arr):
    if len(arr) <= 1:
      return arr
    mid = len(arr) // 2
    left = mergeSort(arr[:mid])
    right = mergeSort(arr[mid:])
    return merge(left, right)

  def merge(L, R):
    i = j = 0
    res = []
    while i < len(L) and j < len(R):
      if L[i] <= R[j]:
        res.append(L[i]); i += 1
      else:
        res.append(R[j]); j += 1
    res.extend(L[i:]); res.extend(R[j:])
    return res
Merge Sort + Inversion Count ek classic problem hai. Merge step mein count karo kitni baar right element left se pehle aata hai!
⚡

5. Quick Sort ⭐

Pivot choose karo, partition karo – Average O(n log n)
▼
Ek pivot element choose karo. Pivot se chhote elements left mein, bade right mein. Phir dono sides pe recursively apply karo. In-place sorting!

Partition Step Visual

Array: [3, 6, 8, 10, 1, 2, 1]   Pivot = 1 (last)
Elements < pivot: [1]  |  Pivot: 1  |  Elements > pivot: [3,6,8,10,2]
Phir recursion: dono sides pe dobara QuickSort! 
Python
  def quickSort(arr, low, high):
    if low < high:
      pi = partition(arr, low, high)  # pivot index
      quickSort(arr, low, pi-1)       # left part
      quickSort(arr, pi+1, high)      # right part

  def partition(arr, low, high):
    pivot = arr[high]  # last element pivot
    i = low - 1
    for j in range(low, high):
      if arr[j] <= pivot:
        i += 1
        arr[i], arr[j] = arr[j], arr[i]
    arr[i+1], arr[high] = arr[high], arr[i+1]
    return i+1
Quick Sort ka worst case O(n²) tab hota hai jab already sorted array ho aur last/first element pivot ho. Isliye random pivot ya median-of-three use karo!
✅Average O(n log n) aur O(log n) space – practically fastest
✅Cache friendly – in-place hai
❌Worst case O(n²), not stable
🏔️

6. Heap Sort

Max Heap banao, ek ek element extract karo – O(n log n)
▼
Pehle array se Max-Heap banao. Phir baar baar max element (root) nikaalte jao aur end mein rakhte jao. Guaranteed O(n log n), in-place! 
Python
  import heapq
  def heapSort(arr):
    # Using heapq for simplicity (returns sorted list)
    h = arr[:]
    heapq.heapify(h)
    return [heapq.heappop(h) for _ in range(len(h))]
🔢

7. Counting Sort & Radix Sort

O(n) sorts – comparison nahi karte!
▼

Counting Sort – O(n + k)

Har element ki frequency count karo, phir cumulative sum se final position nikalo. Comparison hi nahi hota!
Condition: Elements non-negative integers hone chahiye aur range (k) bahut badi nahi honi chahiye. 
Python
  def countingSort(arr, maxv):
    count = [0] * (maxv + 1)
    for x in arr:
      count[x] += 1
    idx = 0
    for i in range(maxv + 1):
      while count[i] > 0:
        arr[idx] = i
        idx += 1
        count[i] -= 1
  # [4,2,2,8,3,3,1] → count → sorted!

Radix Sort – O(nk)

Pehle units digit pe sort karo, phir tens, phir hundreds... Counting Sort ka use karta hai each digit pe. Large integers ke liye O(n)!
🔸Example: [170,45,75,90,802,24,2,66] → units sort → tens sort → hundreds sort → sorted!
Counting Sort best hai jab values 0-1000 range mein hain (k small ho). Radix Sort best hai large numbers ke liye!
🎯
